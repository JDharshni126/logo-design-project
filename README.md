# Eclipse Logo Design Project

A luxury perfume logo branding project created using Canva.

## Objective
To design a clean and professional logo while exploring typography, composition, and brand identity principles.

## Theme
Luxury perfume branding

## Tools Used
- Canva

## Deliverables
- Final Colored Logo
- Black & White Logo Variation

## Design Elements
- Minimal luxury aesthetic
- Typography hierarchy
- Symbolic eclipse/moon concept
- Premium black and gold palette

## Outcome
Created a professional logo suitable for branding and social media applications.
